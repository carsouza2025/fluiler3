# FluiLer Premium 2.1.3 — comece aqui

1. Extraia o ZIP em uma pasta nova, preservando a versão anterior.
2. Leia `AUDITORIA_2.1.3.md`: mostra o que foi confirmado, corrigido e o que depende do ambiente real.
3. Para executar: Node.js 22 ou superior, `npm ci`, `npm run dev`, depois `http://localhost:3000`. Consulte `README.md` para criar o primeiro docente e os códigos de aluno/família.
4. Para visualizar as capas, ícones e personagens, abra `PREVIA_VISUAL.html`. Para testar as telas e atividades, execute o programa completo.
5. Para o AI Studio, siga `ABRIR_NO_GOOGLE_AI_STUDIO.md` e `PROMPT_PARA_AI_STUDIO.md`; preserve frontend e servidor juntos. A interface do destino pode exigir importação por GitHub ou transferência de arquivos.
6. Antes do uso escolar, configure Firestore/IAM e, se desejado, Gemini no servidor. Execute restauração de backup no destino e aplique a etapa F com professores, estudantes e familiares. O banco local é exclusivo do desenvolvimento.

O pacote não contém credenciais nem registros escolares de execução. Os sete textos recebidos foram preservados e os oito acréscimos têm origem editorial identificada. Não representa recuperação de originais ausentes.
